# التدريس والتقييم في عصر الذكاء الاصطناعي: المختبرات

ثمانية مختبرات لمقرر أكاديمية سدايا **USE-EDU-201**، مدتها 35 أو 40 دقيقة ومجموعها خمس ساعات. المختبرات صفحات إرشادية بالعربية: الهدف، والملفات، وخطوات بدقائقها، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرب. لا كود يكتبه المشارك.

يعمل المشارك على أوصاف مهام مقرره هو. والمثال المشترك **معهد سارية للتدريب التقني**، معهد افتراضي، ومقرره «تقييم المخاطر في مواقع العمل» (OSH-214). كل الأسماء والأرقام والتسليمات وهمية.

## ما يحتاجه المشارك

- متصفح، وحساب مجاني في مساعد ذكاء اصطناعي عام من النوع الذي يستخدمه متعلموه. الخطط المجانية تكفي، ولا يُنزَّل أي نموذج على الجهاز.
- برنامج جداول يفتح ملفات CSV، ومحرر مستندات يحفظ سجل الإصدارات لخطة المشروع الختامي.
- ناتج العمل التحضيري: `files/prework_guide.txt`.
- لا يدخل أي مساعد ولا أي ملف عملُ متعلم ولا اسمه.

## تشغيل الحلول

```bash
uv run labs/solutions/check.py            # كل المختبرات
uv run labs/solutions/check.py 1.2 2.1    # بعضها
```

ملف واحد يعلن اعتمادياته، ويحتاج [uv](https://docs.astral.sh/uv/). يقرأ ملفات المشاركين، ويعيد حساب كل رقم مستقلًّا عن المولِّد، ويطابقه بـ`solutions/key.json`، ويطبع `PASS` لكل مختبر. لا يكتب شيئًا على القرص ولا يتصل بأي نموذج.

**ما يُشغَّل فعلًا:** حساب الاتهامات الخاطئة كله (1.2)؛ وقاعدة مقياس الانكشاف على سجلات اختبار الصمود ونصيب المهام المنكشفة من الدرجة (1.1)؛ وفحص البوابتين في خطة اليوم وفي الخريطة المرجعية (1.3)؛ وتطبيق السياسة المرجعية وسياسة ملتبسة على الحالات الثلاث (1.4)؛ وإحصاءات سجلَّي الإصدارات (2.1)؛ ومجاميع الاختبار الشفهي المرجعية وحد الفرق المقبول (2.2)؛ وأوزان السلالم وأزواج الضوابط تحت الميزانية (2.3)؛ ومجاميع إعادة الاختبار والمعيار الذي ما زال مكشوفًا (2.4).

**ما يُشغَّل بمساعد بديل:** كل خطوة يؤديها المشارك في مساعد محادثة، أي اختبار الصمود في 1.1 وإعادة الاختبار في 2.4. المساعد البديل (`solutions/standin.json`) ردود مكتوبة باليد فيها الأخطاء التي يقع فيها مساعد حقيقي، ودرجاتها وضعها كاتب المقرر. **لم يُشغَّل أي مختبر على نموذج حقيقي.** يجري المدرب اختبار الصمود وإعادة الاختبار مرة قبل كل دفعة على المساعد الذي يستخدمه المتعلمون.

**ما هو لعب أدوار:** الاختبار الشفهي في 2.2 بين مشاركين ببطاقتَي دور. درجاته المرجعية من البطاقتين، لا من قياس.

| `redesign/` | قالب الوصف وقالب السلم | |

| `use_log_template.csv`، `capstone_plan_template.txt` | سجل الاستخدام وقالب الخطة | |
